# 🚀 Desafío: 20 Proyectos Spring Boot y Java

Este repositorio contiene mi progreso participando en el **desafío de 20 proyectos Java y Spring Boot**, una serie completa de ejercicios prácticos diseñados para fortalecer y perfeccionar las habilidades en desarrollo backend.

---

## 📚 Sobre el Desafío

Este desafío está formado por **20 proyectos progresivos** que cubren diferentes aspectos del desarrollo backend con Spring Boot, desde operaciones CRUD básicas hasta funcionalidades más avanzadas. Cada proyecto está diseñado para enseñar conceptos clave y mejores prácticas en el desarrollo de APIs REST.

### Objetivos del Desafío

- ✅ Dominar Spring Boot y sus ecosistemas
- ✅ Aprender y aplicar mejores prácticas de desarrollo
- ✅ Construir proyectos reales desde cero
- ✅ Adquirir experiencia práctica en desarrollo backend
- ✅ Crear un portafolio de proyectos funcionales
